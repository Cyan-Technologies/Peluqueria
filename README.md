# Peluquería

Aplicación de gestión de citas, servicios y clientes para peluquería/barbería.  
Proyecto desarrollado por **Cyan Technologies**.

---

## 🎯 Objetivo del Proyecto
Digitalizar y optimizar la operación del negocio:
- Facilitar la reserva y control de turnos/citas.
- Catálogo de servicios y tarifas.
- Agenda y disponibilidad de estilistas/barberos.
- Historial básico de clientes.
